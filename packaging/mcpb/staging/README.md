# FrameShift for Claude Desktop

This bundle runs the native `frameshift-mcp.exe` server on your Windows computer. It uses the same local FrameShift data root as the FrameShift CLI.

## Install

1. Open the `.mcpb` file in Claude Desktop.
2. Review the extension details and approve the install.
3. Open a conversation and use a `frameshift_*` tool.

FrameShift stores persona state on your computer. Catalog search and install tools can contact the public FrameShift service. The bundle does not request API keys or remote account credentials.

Use the FrameShift CLI to manage personas outside Claude Desktop. See the [FrameShift documentation](https://github.com/Ghost-Frame/FrameShift/wiki) for commands, local data paths, and troubleshooting.
